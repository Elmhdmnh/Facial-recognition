# 人脸识别系统 (Face Recognition System)

一个开箱即用的本地人脸识别小工具:**注册人脸 → 实时识别**,带图形界面,普通用户也能用。

- 🖥️ 深色主题图形界面,全程鼠标操作,无需命令行
- 📷 实时摄像头预览,识别结果直接标注在画面上(中文姓名 + 置信度)
- 🧑‍🤝‍🧑 支持注册多个人脸,可删除,可调节匹配阈值
- 🔒 完全本地运行,人脸数据只存在你自己的 `save.json` 里,不上传任何服务器
- 🛡️ 任何错误都会写入 `error.log`,不会闪退

## 快速开始(普通用户)

### 方法一:一键启动(推荐)

1. 安装 [Python](https://www.python.org/downloads/)(3.9 ~ 3.13 均可),安装时**勾选 "Add python.exe to PATH"**
2. 双击 `start.bat`
3. 首次运行会自动安装依赖、下载人脸模型(约 200MB,耐心等待),之后自动打开界面

### 方法二:命令行

```bash
pip install -r requirements.txt
python face_gui.py
```

## 使用方法

1. **注册人脸**:在右侧输入框填姓名 → 点"📷 注册当前人脸" → 正对摄像头,检测到人脸即自动保存
2. **开始识别**:点"▶ 开始识别",画面中:
   - 🟩 绿色框 = 认识的人(显示姓名 + 置信度)
   - 🟧 橙色框 = 陌生人
3. **调节阈值**:滑块控制"多像才算认识"(默认 0.75,调低更宽松、调高更严格)
4. **删除人员**:在"已注册人员"列表中选中 → 点"🗑 删除选中人员"
5. **退出**:点"❌ 退出"或关闭窗口

## 项目结构

```
FaceRecognize/
├── face_gui.py          # 图形界面主程序(推荐使用)
├── facerecognize.py     # 旧版命令行程序(按 x 检测,按 q 退出)
├── start.bat            # 一键启动脚本
├── requirements.txt     # 依赖清单
├── save.json            # 人脸数据(自动生成,注意备份)
└── error.log            # 错误日志(出错时自动生成)
```

## 常见问题

**Q: 启动后提示"无法打开摄像头"?**
摄像头被其他程序(微信、腾讯会议等)占用时会出现。关闭占用程序后重试。

**Q: 识别不准 / 乱认人?**
- 调节右侧阈值滑块:调高更严格(不易误认),调低更宽松(更易认出)
- 重新注册一张光线好的正面照

**Q: 程序出错闪退?**
任何错误都会写入同目录的 `error.log`,把它发给开发者即可定位。

**Q: 想用 GPU 加速?**
安装 GPU 版依赖即可自动启用:
```bash
pip uninstall onnxruntime
pip install onnxruntime-gpu
```
并确保电脑有 NVIDIA 显卡 + CUDA 环境。

**Q: 换电脑/换模型后识别不了旧数据?**
`save.json` 里保存的是模型提取的特征向量,换模型后需重新注册。程序会自动兼容未归一化的旧数据。

## 技术说明

- 人脸检测/识别:[InsightFace](https://github.com/deepinsight/insightface) `buffalo_l` 模型
- 界面:Tkinter(标准库)+ Pillow
- 比对方式:L2 归一化后的余弦相似度,阈值默认 0.75
- 数据格式:`save.json` 为 JSON 数组,每项 `{"name": 姓名, "embedding": [512维向量]}`
